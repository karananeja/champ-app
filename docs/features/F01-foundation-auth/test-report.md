## 3. Known limitations

- **Google sign-in was not tested against real Google.** No OAuth client exists. The server path is covered with a mocked verifier. The GIS button rendering needs a real `GOOGLE_CLIENT_ID` with `http://localhost:5173` as an authorised origin.
- **`pnpm db:reset`** (`prisma migrate reset --force` + seed) was not run during verification, to avoid wiping the dev database. Test and E2E databases are reset by `apps/api/scripts/prepare-db.ts`, which refuses any database whose name doesn't end in `_test` or `_e2e`.
- **The rate limiter uses in-memory storage.** It resets when the API restarts, and it isn't shared between instances. This is fine for the single-process local MVP.
- **The API runs from TypeScript via `tsx`** (dev and `pnpm start`). `pnpm build` type-checks the API but doesn't produce a compiled bundle (see D-042).
- **MinIO is provisioned but unused in F01.** The bucket is not created yet; that comes with the first feature that stores files.
- The refresh cookie is `Secure` only when `NODE_ENV=production`.
- If an SA changes a signed-in user's role or delegation, the server enforces it at once. That user's UI (menus and buttons) updates only after a page reload, or after the next token refresh (at most 15 min).
